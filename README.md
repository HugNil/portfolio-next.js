## Starta lokalt

Krav: Node.js och npm installerat.

Installera alla dependencies från projektroten:

```bash
npm run install-all
```

Starta utvecklingsservern:

```bash
npm run start
```

Öppna sedan:

```bash
http://localhost:3000
```

## Vanliga kommandon

Kör bara frontend-appen:

```bash
cd frontend
npm run dev
```

Bygg projektet för produktion:

```bash
npm run build
```

Starta en byggd production-version:

```bash
cd frontend
npm run build
npm run start
```
